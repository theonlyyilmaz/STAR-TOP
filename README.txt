Project: 'STAR-TOP' created on 2026-11-26
Author: YILMAZ GÜLMEZ -theonlyyilmaz- <gulmezylmazz@gmail.com>

STAR-TOP is an enterprise network simulation project developed using GNS3.

The project demostrated a multi-router network architecture with dynamic routing (OSPF), VLAN segmentation, inter-VLAN routing, DHCP, NAT and Acces Control Lists (ACL).

It includes a company network connection, seperate lab network segments, centralized routing, and controlled network access.

The main objective is to design, configure and test a scalable enterprise network infrastructure using Cisco routers, Layer 3 switching and VPCS end devices.
